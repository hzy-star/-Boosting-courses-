# 在线壹佰分 - 多账号自动刷课

基于 Python + Playwright 的桌面刷课工具：
**多账号并行、自定义倍速、自动登录 → 进入指定课程 → 自动播放 → 播完自动下一节，并内置人脸/活体检测绕过。**

会自动跳过后台已记录学时的集，从「未学习」的章节继续，不强制从头重看。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `gui.py` | **刷课工具（推荐）**：图形界面，填账号 + 选本人录像 → 自动切人脸片段 → 一键刷课 |
| `main.py` | 核心：读取配置、并行登录、进课程、注入脚本、视频切片、faceCompare 拦截 |
| `injected.js` | 注入到网页里的刷课逻辑（倍速、自动下一节、防暂停、按活体提示转头、跳过已记录的集） |
| `config.ini` | 默认设置（GUI 里也能改倍速/并行/窗口等） |
| `accounts.txt` | 账号列表，每行 `身份证号----密码----起始集----课程序号`（GUI 会自动写） |
| `faces/<身份证号>/` | 该账号的人脸片段 `front.mp4 / turnA.mp4 / turnB.mp4`（inject 模式，GUI 上传录像后自动切） |
| `faces/<身份证号>.y4m` | 该账号的假摄像头视频（file 模式用；找不到回退根目录 `face.y4m`） |
| `ffmpeg.exe` / `ffprobe.exe` | 视频切片所需，**必须放在本目录或系统 PATH** |
| `run_gui.bat` | 不打包，直接启动 GUI 工具 |
| `run.bat` | 不打包，按 `accounts.txt` 命令行运行 |
| `build.bat` | 打包成 `dist\刷课工具\刷课工具.exe` |
| `requirements.txt` | 依赖清单 |

## 刷课工具（GUI）用法（推荐）

1. 确保本目录或系统 PATH 里有 `ffmpeg.exe` 和 `ffprobe.exe`（用于把录像切成人脸片段）。
2. 双击 `run_gui.bat`，或打包后运行 `dist\刷课工具\刷课工具.exe`。
3. 在窗口里填写并添加账号：
   - **身份证号 / 密码**
   - **起始集**：从第几集开始看（已看过的会自动跳过，填靠前一点也没关系）
   - **课程序号**：你「我的学习 → 课程」列表里第几门课，按排序填（`1` = 第一门，`2` = 第二门……）
   - **选择本人录像…**：选该账号**本人录制**的视频（已在 `faces/<身份证号>/` 放好片段的可留空）
   - 点 **＋ 添加到列表**，可重复添加多个账号。
4. 顶部可设倍速、并行数、浏览器内核、是否隐藏窗口。
5. 点 **▶ 开始刷课**：工具会先把每个账号的录像切成 `front/turnA/turnB` 三段，再按并行数打开 Edge/Chrome 自动刷课，日志实时显示。
6. 点 **■ 停止** 或关闭窗口即停止并清理浏览器。

> **录像要点**：本人出镜、白墙背景、平视镜头、光线均匀，依次「正对镜头约 3 秒 → 慢慢向左转头 → 回正 → 向右转头 → 回正」约 15 秒。必须是**该账号注册时的本人脸**，否则人脸比对不通过。

> **切片去向**：用 exe 运行时，切出来的片段写在 **exe 同目录**下，即 `dist\刷课工具\faces\<身份证号>\`；用 `run_gui.bat`/源码运行时则写在项目根目录的 `faces\` 下。两套互相独立。

> **多门课程**：如果你的「课程」列表里有多门课，用「课程序号」按排序选要刷哪一门；找不到该序号时会退回用 `course_name`，再退回点第一门。

## 准备工作（只需一次，源码方式运行才需要）

1. 安装 Python 3.9+（勾选 Add to PATH）。
2. 安装依赖：

```bash
pip install -r requirements.txt
```

3. 浏览器：默认调用系统自带的 **Microsoft Edge**（Win10/11 已预装），无需额外下载。
   若没有 Edge/Chrome，可执行下面命令并把 `config.ini` 的 `browser_channel` 留空：

```bash
playwright install chromium
```

## 命令行 / accounts.txt 方式

1. 打开 `config.ini` 调整倍速、并行、摄像头模式等。
2. 打开 `accounts.txt`，每行一个账号，格式 `身份证号----密码----起始集----课程序号`
   （起始集不填默认第 1 集；课程序号不填默认第 1 门，兼容旧的三段写法）：

```
610526199903062516----062516----12----1
身份证号2----密码2----1----2
```

3. 运行：双击 `run.bat`（源码方式），或打包后运行 `dist\刷课工具\刷课工具.exe`。

每个账号会打开一个浏览器，自动完成：
登录 → 我的学习 → 课程 → 第 N 门课「继续学习」 → 从未记录学时的章节开始播放 → 播完自动进入下一节。

## 打包成 EXE

双击 `build.bat`，完成后产物在 `dist\刷课工具\` 目录（`刷课工具.exe` + 依赖文件夹，onedir 形式）。
把整个 `dist\刷课工具` 文件夹拷给别人即可；对方需保证该目录里有 `ffmpeg.exe`、`ffprobe.exe`，运行前可编辑里面的 `config.ini` / `accounts.txt`。

## config.ini 参数

| 参数 | 说明 |
| --- | --- |
| `login_url` | 登录页地址（机构不同可改 organization_id） |
| `speed` | 播放倍速（`1` / `2` / `4` / `8` / `16`） |
| `max_parallel` | 同时并行的账号数（建议 3~5；`0` = 全部一起跑） |
| `headless` | `false` 显示窗口 / `true` 后台隐藏 |
| `course_name` | 指定课程名（备用）；GUI 里建议直接用「课程序号」按排序选 |
| `max_minutes` | 每账号最长运行分钟数（`0` = 不限制，需手动关窗口） |
| `browser_channel` | `msedge` / `chrome` / 留空用 chromium |
| `login_attempts` | 登录最多提交几次（首次+重试）。该站连续失败超 2 次会被限登，建议 ≤ 2 |
| `bypass_face` | `true` = 拦截 faceCompare：优先把真实抓拍帧转给服务器做真比对，只有被拒时才伪造成功放行 |
| `camera_mode` | `inject`（注入脚本+画布接管，支持按提示转头）/ `file`（用 Y4M 文件当假摄像头，画质更干净）。**GUI 固定用 inject** |

## 人脸 / 活体检测说明

- 假摄像头喂的是该账号**本人录像**切出的片段；`inject` 模式会按页面「向左/向右转头」提示实时切换 `front/turnA/turnB`。
- `bypass_face=true` 时拦截 `/api/course/faceCompare`：先用当前真实帧让服务器真比对，清晰正脸才会真通过、后台才真记学时；服务器拒绝时伪造成功放行，保证视频不被卡住（但那一次不计学时，后续会再抓拍重比）。

## 注意事项

- 倍速过高（如 16x）部分情况可能被判异常，建议按需调低。
- 网站页面改版时，需相应更新 `injected.js` 里的选择器（课程卡片 `div.study`、「继续学习」按钮 `p.button`、章节、lessonTree 接口等）。
- 账号密码为明文存储，请妥善保管 `accounts.txt`。
